# 📱 NFC Smart Attendance & Analytics System
A modern, Glassmorphism-themed Attendance Tracker built for B.Tech students. It features physical NFC tap integration, Smart Bunk Analytics, and an Exam Target Predictor.

## 🚀 Features
- **Smart Bunk Manager:** Calculates exactly how many classes you can safely skip.
- **Exam Predictor:** Set your exam date and see your expected attendance.
- **Glassmorphism UI:** Premium, responsive dashboard.
- **Subject-Wise Analytics:** Track individual subject progress.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript
- **Backend:** Java Spring Boot
- **Database:** PostgreSQL (Supabase)
- **Deployment:** Vercel (Frontend) & Render (Backend)
